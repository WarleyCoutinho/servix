# 🧩 PROMPT DE IMPLEMENTAÇÃO — Botão Ativar/Desativar Stripe + Aviso Persistente

---

## 🚨 REGRA ABSOLUTA

> O fluxo da Stripe **não pode ser tocado em nenhum ponto**.
> Todos os estágios continuam funcionando exatamente como estão hoje.
> Esta implementação é apenas **1 botão no painel Admin/Suporte** + **1 aviso visual na tela do profissional**.
> Nada mais é alterado.

---

## 🎯 DOIS CENÁRIOS DE USO

### Cenário 1 — Problema temporário com a Stripe

> A conta Stripe está em análise, com documentação pendente ou bloqueada temporariamente.
> O Admin/Suporte ativa o acesso manual para o profissional continuar usando o sistema.
> Quando a Stripe resolver e ficar `ACTIVE` via webhook → **o aviso some automaticamente** e a Stripe volta a funcionar normalmente.

### Cenário 2 — Profissional optou por não usar a Stripe

> A conta Stripe está ok, mas o profissional não quer usar.
> O Admin/Suporte **desabilita a Stripe** do profissional.
> O aviso aparece na tela dele e **fica para sempre** até ele decidir voltar.
> Quando ele quiser reativar, basta o Admin/Suporte **habilitar a Stripe novamente** — e tudo volta ao normal automaticamente.

## 🗄️ BANCO DE DADOS

> ✅ **Campos já existem. Não criar, não alterar, não migrar nada.**

Campos utilizados:

| Campo                   | Cenário 1 (problema Stripe) | Cenário 2 (optou por não usar) |
| ----------------------- | --------------------------- | ------------------------------ |
| `acceptPayAfterService` | `TRUE` (temporário)         | `TRUE` (indefinido)            |
| `stripeAccountStatus`   | `'ACTIVE'` (manual)         | `'INACTIVE'` (desabilitado)    |

---

## 🔁 LÓGICA DO SISTEMA

```
O profissional pode usar o sistema?

  SE acceptPayAfterService = TRUE
    → LIBERADO (independente da Stripe)

  SENÃO
    → Verificar stripeAccountStatus (lógica original, sem alteração)
    → SE stripeAccountStatus = 'ACTIVE' → LIBERADO com todos os benefícios
    → CASO CONTRÁRIO → BLOQUEADO

─────────────────────────────────────────────

EXIBIR aviso na tela do profissional?

  SE acceptPayAfterService = TRUE
  E stripeAccountStatus ≠ 'ACTIVE' via Stripe legítima (webhook)
    → EXIBIR aviso permanente

  SE Stripe aprovada via webhook (Cenário 1 resolvido)
    → REMOVER aviso automaticamente
    → stripeAccountStatus volta ao fluxo normal da Stripe

  SE Admin/Suporte reabilitar a Stripe (Cenário 2 resolvido)
    → REMOVER aviso
    → Stripe volta a funcionar normalmente
```

## 🔧 BACKEND — Endpoints

```
PATCH /admin/professionals/:id/manual-activation
PATCH /support/professionals/:id/manual-activation
```

### Body — Ativar acesso manual (Cenário 1):

```json
{
  "activate": true,
  "reason": "STRIPE_ISSUE"
}
```

### Body — Desabilitar Stripe por escolha (Cenário 2):

```json
{
  "activate": true,
  "reason": "PROFESSIONAL_CHOICE"
}
```

### Body — Reativar Stripe:

```json
{
  "activate": false
}
```

### Lógica:

```
SE activate = true E reason = 'STRIPE_ISSUE':
  → acceptPayAfterService = TRUE
  → stripeAccountStatus = 'ACTIVE' (temporário)
  → Registrar log com motivo

SE activate = true E reason = 'PROFESSIONAL_CHOICE':
  → acceptPayAfterService = TRUE
  → stripeAccountStatus = 'INACTIVE' (desabilitado por escolha)
  → Registrar log com motivo

SE activate = false:
  → acceptPayAfterService = FALSE
  → stripeAccountStatus retorna ao fluxo normal da Stripe
  → Registrar log
```

### Segurança:

- ✅ JWT obrigatório
- ✅ Somente roles `ADMIN` e `SUPORTE` — qualquer outra role retorna `403 Forbidden`

## 📱 AVISO PERSISTENTE NA TELA DO PROFISSIONAL

### Regras:

- Aparece em local **discreto mas sempre visível** (banner fixo no rodapé ou topo com baixa opacidade)
- O profissional pode **minimizar** mas **nunca fechar definitivamente**
- Toda vez que abrir o sistema, o aviso estará lá
- **Some automaticamente** quando a Stripe for reativada

### Visual do aviso:

```
┌─────────────────────────────────────────────────────────────────┐
│  ⚠️  Você está usando o sistema sem a Stripe.                  │
│  Você não tem acesso a:                                         │
│  ❌ Pagamento online · ❌ PIX integrado · ❌ Cobrança automática │
│  ❌ Proteção no-show · ❌ Histórico financeiro · ❌ Relatórios   │
│  ❌ Comissão automática · ❌ Período 0% de taxa                  │
│                                                                 │
│  Essa foi sua escolha. Ative a Stripe para ter esses           │
│  benefícios.                      [ Quero ativar a Stripe ]    │
└─────────────────────────────────────────────────────────────────┘
```

> O botão **"Quero ativar a Stripe"** apenas abre um canal de contato ou redireciona para o suporte — **não ativa nada automaticamente**. Somente Admin/Suporte pode reativar.
