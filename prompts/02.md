# Prompt 1 — Criar a tabela:

No meu schema.prisma, adiciona um model chamado Upload com os campos: id (uuid), nomeArquivo (String), tipoArquivo (String), tamanho (Int), dados (Bytes), createdAt (DateTime default now). Depois rode a migration.

# Prompt 2 — Rota de upload:

Reescreve o arquivo app/api/upload/route.ts para salvar o arquivo no banco de dados usando Prisma no model Upload. Converte o arquivo para Buffer e salva no campo dados. Antes de salvar, deleta todos os registros com createdAt menor que 30 dias atrás. Retorna o id do upload criado.

# Prompt 3 — Rota para servir o arquivo:

Cria a rota app/api/uploads/[id]/route.ts que busca um Upload pelo id no banco usando Prisma e retorna o arquivo com o Content-Type correto e Content-Disposition inline com o nome do arquivo. Se não encontrar retorna 404.

# Prompt 4 — Atualizar o frontend:

Atualiza o frontend para que ao fazer upload de arquivo, envie para /api/upload via FormData. Após o upload, use o id retornado para montar a URL /api/uploads/[id] e exibir o arquivo.
