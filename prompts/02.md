🔹 Prompt 2 — Fluxo de Primeiro Login

Implementar a lógica de primeiro login, na qual o usuário deve obrigatoriamente escolher entre as opções Cliente ou Proprietário.

Essa escolha deve:

Ser apresentada apenas no primeiro acesso

Ser persistida no banco de dados

Não permitir alteração posterior sem ação administrativa ou fluxo específico

O sistema deve garantir que:

A role escolhida seja aplicada imediatamente

O usuário seja direcionado automaticamente para o fluxo e dashboard correspondente

A experiência seja consistente e segura tanto no backend quanto no frontend

Essa implementação deve seguir boas práticas de controle de estado e autorização, assegurando um onboarding claro e profissional para o usuário.
